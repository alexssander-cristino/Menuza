# Ícone do Menuza

Coloque sua imagem PNG quadrada nesta pasta com o nome exato `app_icon.png`.

Caminho final: `mobile_flutter/assets/app_icon.png`

Recomendado: 1024 × 1024 px. Ao enviar a imagem para o GitHub, o workflow Android vai gerar os ícones do aplicativo e compilar o APK automaticamente.

Não precisa editar o código para trocar a imagem: substitua esse arquivo pelo seu próprio `app_icon.png`.
